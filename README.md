# 🌐 Samuel (СЕМИ) — Personal Portfolio Website

Portfolio pribadi ultra-modern, premium, dan dinamis yang dibangun menggunakan **HTML5**, **Vanilla CSS**, dan **Vanilla JS** (tanpa framework berat / Tailwind CSS). Website ini dirancang dengan estetika *Premium Dark Mode*, aksen *Neon Lime* (`#a3e635`), efek *glassmorphism*, dan animasi mikro yang sangat halus.

> Lihat repositori portofolio langsung di [JustSEMI/justsemi.github.io](https://github.com/JustSEMI/justsemi.github.io).
